# Triage Labels

相关技能使用五个 canonical triage roles。本文件将这些角色映射到仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义 |
| ---------------------------- | ------------------------- | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个角色（例如 “apply the AFK-ready triage label”）时，使用本表中对应的 label 字符串。

如仓库实际使用不同词汇，可编辑右侧列进行匹配。
